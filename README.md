# MEET

## 프로젝트 소개

**MEET**는 개인 일정 관리와 일정 공유를 하나의 서비스에서 편리하게 수행할 수 있도록 하는 일정 관리 플랫폼이다.

현재 사람들은 일정을 공유할 때 휴대폰 기본 캘린더 캡처, 에브리타임 시간표 공유, 메신저를 통한 직접 전달 등 서로 다른 방식과 애플리케이션을 사용한다. 이 때문에 일정 공유 방식이 통일되지 않고, 그룹이나 개인별로 공개 범위를 세밀하게 조절하기 어렵다는 문제가 있다.

또한 기존 일정 관리 서비스는 개인 일정 관리에는 적합하지만, 친구나 그룹 단위 일정 공유, 일정별 공개 범위 설정, 메신저 기반 알림과 같은 기능을 충분히 제공하지 못하는 경우가 있다.

MEET는 이러한 불편함을 개선하기 위해 **카카오 계정 및 카카오 관련 API를 활용하여 사용자에게 익숙한 환경에서 일정 관리와 공유가 가능하도록 하는 것**을 목표로 한다.

또한 서울시 공공데이터를 활용하여 지역별 실시간 인구 밀집도와 과거 혼잡 데이터를 제공함으로써, 사용자가 약속 장소와 일정을 계획할 때 추가적인 정보를 확인할 수 있도록 한다.

---

## 주요 기능

### 1. 카카오 기반 사용자 및 공유 기능
- 카카오 계정 API를 활용한 로그인 및 사용자 연동
- 카카오톡 기반 친구 및 그룹과 일정 공유
- 단체 채팅방 등 카카오톡을 활용한 일정 공유 접근성 제공

### 2. 개인 일정 관리
- 개인 일정 등록, 수정 및 삭제
- 친숙하고 직관적인 캘린더 기반 UX/UI 제공
- 월간 달력을 기본 화면으로 제공
- 특정 날짜 선택 시 해당 날짜의 시간대별 세부 일정 확인
- 일정 선택 시 장소, 시간, 참여자 등 일정 상세 정보 확인

### 3. 일정 공개 범위 설정
각 일정마다 공개 범위를 개별적으로 설정할 수 있다.

- **그룹 공개**: 사용자가 속한 그룹 중 공개할 그룹 선택
- **개인 공개**: 특정 친구를 선택하여 일정 공개
- **비공개**: 본인만 확인 가능한 개인 일정

### 4. 그룹 일정 관리
- 사용자가 속한 그룹별 일정 관리
- 그룹마다 서로 다른 색상을 적용하여 캘린더에서 일정을 시각적으로 구분
- 그룹 구성원 간 일정 공유 및 확인

### 5. 카카오톡 일정 알림
- 일정이 가까워지면 카카오톡을 통해 알림 제공
- 예정된 약속이나 중요한 일정에 대한 리마인더 기능 제공

### 6. 서울시 인구 데이터 연동
서울시 공공데이터를 활용하여 일정 및 장소 선택에 도움이 되는 정보를 제공한다.

- 지역별 실시간 인구 밀집 현황 조회
- 지도 위에서 지역별 혼잡도를 색상으로 시각화
- 과거 인구 데이터를 기반으로 특정 지역의 혼잡도 변화 확인
- 최근 1년, 6개월, 3개월, 1개월, 1주일, 3일, 1일 등의 기간별 데이터 제공

이를 통해 사용자는 약속 장소를 선택할 때 현재 혼잡도뿐 아니라 최근 혼잡 경향도 함께 참고할 수 있다.

## 핵심 목표

MEET는 단순한 개인 캘린더를 넘어,

**개인 일정 관리 + 친구 및 그룹 일정 공유 + 공개 범위 관리 + 카카오 기반 알림 + 지역 혼잡 정보**

를 하나의 서비스에서 제공하는 것을 목표로 한다.

사용자가 기존에 사용하던 다양한 일정 공유 방식을 하나로 통합하여, 보다 편리하고 자연스럽게 일정을 관리하고 공유할 수 있는 환경을 제공한다.
